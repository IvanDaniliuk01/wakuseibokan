💡 Ejercicio para entender el gimbal lock:

1. Apretá el preset "Gimbal lock (pitch=90°)". El Otter queda con el morro al cielo.

2. Ahora mové el slider de yaw. El Otter rota alrededor del eje vertical.

3. Volvé yaw a 0 y mové el slider de roll. El Otter rota de la misma forma que con yaw.

4. Los dos sliders producen el mismo efecto visual = perdiste un grado de libertad. Eso es gimbal lock.

Mirá los anillos: amarillo (yaw) y azul (roll) están alineados en este caso.
