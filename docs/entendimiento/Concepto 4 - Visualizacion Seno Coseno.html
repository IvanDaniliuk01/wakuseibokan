💡 Cosas que tenés que probar:

1. yaw = 0°: el cateto rojo desaparece (sin(0)=0), el azul tiene longitud 100 (cos(0)=1).

2. yaw = 90°: lo opuesto. Cateto azul desaparece, rojo tiene longitud 100.

3. yaw = 45°: los dos catetos miden lo mismo (≈70.7). Triángulo "balanceado".

4. yaw = 180°: cos(180°) = -1, el cateto azul se invierte (apunta al norte). Componente negativa = dirección opuesta.

5. Movelo lento y observá cómo crecen y decrecen los dos catetos al mismo tiempo. Es como dos olas desfasadas.
