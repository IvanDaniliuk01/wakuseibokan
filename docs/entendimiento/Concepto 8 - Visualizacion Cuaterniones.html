Presets

💡 Probá esto para entender lo importante:

1. Apretá "Pitch 90°". Mirá la equivalencia Euler: pitch=90° → caso de gimbal lock en Euler. Pero el cuaternión es solo (0.707, 0.707, 0, 0), sin nada raro.

2. Ahora movés cualquier slider apenas un poco. Los 4 valores del cuaternión cambian suavemente. Compará con Euler: la conversión puede mostrar saltos drásticos.

3. Apretá "▶ Animar al origen". Vas a ver una interpolación suave (slerp) desde la orientación actual hasta la identidad. Los cuaterniones son IDEALES para esto.

4. Negación: si ponés ángulo 360° y comparás con ángulo 0°, las dos son la misma rotación física. Pero el cuaternión es (−1, 0, 0, 0) vs (1, 0, 0, 0) — esto es la doble cobertura.
